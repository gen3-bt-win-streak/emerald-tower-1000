# エメラルド バトルタワー（ダブル）1000連勝プロジェクト

## 目的
エメラルド・バトルタワー（ダブルバトル）で **1000連勝** を達成する構築と行動指針を、感覚ではなくデータベースとして体系化する。

## この目標の重さ（まず現実を知る）

- ダブルの既知世界記録は **799連勝**（Lv100・エミュレータ）。シングルでは 1090連勝、2500連勝超の報告がある。
  → **ダブル1000連勝は「既知の世界記録超え」**。攻略ではなく記録挑戦として設計する必要がある。
- 必要勝率の計算：
  - 成功率50%を狙う場合ですら、1戦あたり勝率 **99.93%以上**（0.99931^1000 ≈ 0.5）
  - 成功率90%なら1戦あたり **99.99%**（負けは1万戦に1回レベル）
  → 結論：**「相手に乱数を振らせる回数」を極限まで減らす構築・立ち回りがすべて。**
    急所（第3世代は1/16）・一撃技（30%）・クイッククロー等は、試行回数を与えた時点で負け筋になる。
    だいばくはつで最速で盤面を終わらせるコンセプトは、この観点で理論的に正しい。

## コアコンセプト（現行案）

- 初手：**ゲンガー ＋ メタグロス**
- 後発：**ラティオス ＋ 4匹目（カビゴン最有力）**
- 勝ち筋：
  1. メタグロスのだいばくはつで盤面崩壊（ゲンガーはゴーストなので**味方の爆発を無効化**）
  2. 爆発後はラティオスで制圧
  3. 耐久相手・終盤はゲンガーのほろびのうた（保険であり毎試合の技ではない）

## 今回の調査で判明した、元プランへの重要な修正点

1. **ほろびのうたゲンガーは第3世代で正規入手可能**【確定】
   ♂ムウマ（Lv46でほろびのうた習得）×♀ゴース系をエメラルドの育て屋で預ける遺伝技。
   ただし**ゴース系はホウエンに出現しない**ため、FRLG（ファイアレッド/リーフグリーン）から♀個体の輸送が必要。
2. **ゲンガーは味方メタグロスのだいばくはつを型抜きで無効化**（ノーマル技⇒ゴーストに無効）【確定】
   → 爆発ターンの「まもる」は爆発対策ではなく**敵2体の攻撃対策**。安全が確認できるなら、爆発ターンにゲンガーは攻撃やほろびのうたを撃てる（行動回数で得）。
3. **負け筋に「しめりけ」を追加**【確定】
   しめりけ（ゴルダック・ニョロボン・ニョロトノ・ヌオー等）が場にいると、だいばくはつ・じばくは**発動自体が不可能**。ゴーストより深刻（爆発が「透かされる」のではなく「撃てない」）。
4. **負け筋に「ぼうおん」を追加**【確定】
   ぼうおん（マルマイン・バクオング・バリヤード等）にはほろびのうたが無効。爆発プランとほろびプランの両方を消してくる相手が存在しうる。
5. **第3世代にチームプレビューは存在しない**【確定】
   「相手にゴーストがいるか？」は開幕時点では**見えている先頭2体＋トレーナータイプからの推測**になる。
   → 作るべきDBの本命は「トレーナータイプ×見えている2体 → 裏2体の候補と危険度」の推定表。
6. **「トリック」は第3世代の敵プールにはほぼ存在しない可能性が高い**【要検証】
   Phase 2 リストから外せるかもしれない（外せれば負け筋が1つ減る）。
7. **フロンティアブレーン（リラ）はシングル限定**【確定】
   ダブルにはブレーン戦が存在しない。7戦ごとにセーブして中断可能。
8. **だいばくはつの教え技はキナギタウンで1ROMにつき1回のみ**【高確度】
   爆発持ちを2匹以上用意するなら別ROMからの輸送が必要。現行案（メタグロスのみ）なら問題なし。
