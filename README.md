# エメラルド バトルタワー（ダブル）1000連勝プロジェクト

## 目的
エメラルド・バトルタワー（**ダブルバトル・オープンレベル**）で **1000連勝** を達成する構築と行動指針を、
感覚ではなく一次データ（pokeemerald逆コンパイル）のデータベースとして体系化する。

## この目標の重さ

- **オープン・ダブルの現行世界記録は799連勝**（Lv100・エミュ）。シングルはLv50で3010連勝、オープンで1090連勝。
  → **1000連勝＝ダブル世界記録の正面更新**。
- 必要勝率：成功率50%狙いでも1戦あたり **99.93%**（0.99931^1000≈0.5）。
  → すべての設計原則は「**相手に乱数を振らせる回数の最小化**」に帰着する。
  だいばくはつ速攻はこの観点で理論的に正しく、しかも**第3世代ダブルの爆発・じしんは複数対象でも減衰なし**（検証済み）。

## 検証で判明した主な事実（抜粋）

**プランを強化する事実**
1. じしん・だいばくはつは第3世代ダブルで**減衰なしフルダメージ**（0.5倍は相手2体対象技のみ）
2. 敵AIはほろびのうたを受けると「倒れる最終ターン」にしか交代しない（唯一の100%交代トリガー）→ 敵残り2匹で歌えば確殺
3. まもる持ちは定常プールで18セットのみ。AIの連続まもるは−2でほぼ来ない → 「1回まもらせてから爆発」が正解手順
4. 敵の爆発持ちはHP50%以下でしか自爆してこない（HP80%以上ではほぼ撃たない）→ 予測可能
5. **オープンで増える脅威はカイリュー/バンギ/三鳥三犬最強の32セットだけ**。一撃技・催眠・ゴースト・しめりけ・
   ぼうおん・まもる等の「詰み系」リストはLv50と完全に同一 → 対策対象が明確

**プランに制約を課す事実**
1. **相打ち全滅＝負け**（第3世代タワーの引き分け仕様）→ 爆発/ほろびの起動条件に「生存者を残せること」を必ず含める
2. しめりけ（ゴルダック/ヌオー）の特性率は**ちょうど50%**で判別不能 → 見えたら爆発禁止
3. **ムウマはリーフグリーン限定**（ななしのどうくつ）。エメラルドでは入手不可 → LGが必須機材
4. 徘徊ラティオスに**シンクロは無効**。個体はテレビ回答の瞬間に固定（厳選リセット位置に注意）
5. TM30シャドーボールは1ROM1個（おくりびやま）→ メタグロス優先、ゲンガーの技はゲームコーナーTMで
6. 敵の一撃技持ち23セット・クイッククロー75セットが定常プールに常駐。QC発動は20%
