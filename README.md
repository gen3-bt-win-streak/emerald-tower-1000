## 今の構築（v6・実機で走行中）

**メタグロス／ラティオス／ニョロトノ／カビゴン**

- ラティオスとメタグロスで可能な限り敵を制圧。
- 不利なポケモンにはカビゴン、ニョロトノで受けながらあくび、滅びの歌で積み対策、詰めも行う。
- しめりけで相手の爆発も止める。

v6最高 391連勝 ／ 自己ベスト 613連勝（v4時代）／ 目標 1000連勝（世界記録 1316）
