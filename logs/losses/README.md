# logs/losses/ — 敗戦ログ

負けた試合（記録したい勝ち試合も）の流れを1戦1ファイルで置く。ファイル名は `<日付>-<停止時の連勝>.md`。
書くのは [タワー敗戦ログ](../../tools/losslog/README.md) のページで、書き出しをチャットに貼ると `/losslog` が `tools/losslog/ingest.py` でここに保存する。

各ファイルは、人が読む本文（Markdown の表）と、末尾の解析用 `json` ブロック（`v: 1`）からなる。
本文は書き出し当時のまま残し、後から分かったこと（型の確定・正着・確率）は本文の下に追記してよい。json は手で直さない。
