# 20. 敵の「だいばくはつ」使用AI（1枚もの）

> **スコープ限定**：このドキュメントは **敵AIがいつ爆発を選ぶか** だけを扱う（**ダブル前提**。§3.5にダブル固有の帰結）。
> こちらの爆発の通り・撃てない盤面19.6%・被害表などは
> [01](01-danger-pokemon.md) §3 / [06](06-no-boom-playbook.md) / [12](12-playbook.md) §4.2 を参照。
> 出典は `data/battle_ai_scripts.s` の原文。最終更新 2026-08-17。

---

## 0. 3行で

1. **敵に控えが1体でもある限り、爆発への減点はゼロ**。＝「常に飛んでくる」が正しい前提で、ハードなHPゲートは存在しない。
2. HP帯の抑制は第2層にあるが、**満タンの−3は「敵が先手側」のときしか乗らない**。こちらが先手＝低速の敵は満タンから普通に爆発する。
3. **−10は禁止フラグではなく点数ペナルティ**。他技がPP切れになると点数無関係に爆発が出る。

---

## 1. 第1層 `AI_CBM_Explosion`（撃たせない条項）

```
if 相性x0（ゴースト）              → -10（実質禁止）
if 相手の特性 == しめりけ          → -10（実質禁止）
count_usable_party_mons AI_USER    → 0でなければ即終了 ＝ ペナルティ一切なし
count_usable_party_mons AI_TARGET  → 0でなければ -10（実質禁止）
それ以外                           → -1 のみ
```

※ `count_usable_party_mons` は**控え**の数（場に出ている個体は数えない）。

| 敵の控え | こちらの控え | 爆発の扱い | 実戦での意味 |
|---|---|---|---|
| **1体以上** | 問わず | **減点ゼロ** | **常に飛んでくる前提**。HPで安全になる区間は無い |
| 0（敵ラス1） | 1体以上 | **−10** | **こちらに控えがある限り、敵ラス1は爆発してこない** |
| 0（敵ラス1） | **0** | **−1のみ** | ★**危険窓。撃ってくる** |

### 読み違えやすい点

- 「敵ラス1は爆発しない」は**こちらの控えが残っている場合だけ**の話。自軍が2体になった瞬間に条項が反転する。
- **−10は禁止ではない**。基礎点100からの比較選択なので、**爆発以外の技がPP切れになると点数と無関係に爆発しか選べなくなる**。
  → 敵ラス1の爆発持ちを**まもる／受け回しで長期ステールしない**（オバヒ・ふぶき等のPP5技から枯れる）。
  2026-08-11 のユーザー質問「絶対に爆発しないコードか？」への正確な回答はこれ。

## 2. 第2層 `AI_CV_SelfKO`（HP帯による加減点）

| 敵の残HP | 補正 | 実質 |
|---|---|---|
| **≥80%**（**かつ敵が先手側**） | 約80%で **−3** | ほぼ撃たない |
| 51-79% | 約80%で **−1** | 消極的 |
| **≤50%** | 50%で **+1** | 撃ってくる |
| **≤30%** | さらに **+1** | 高確率で撃つ |

- しきい値は **80/50/30 の3段**（`hp < maxHP × N/100` の整数比較。**80%ちょうどは ≥80% 側**）
- 乱数は **206/256 ≈ 80.5%** と **128/256 = 50%**
- 回避ランク条件もあり（相手の回避+1で −1、+4でさらに50%で −1）

### ★最重要：満タンの抑制は「敵が先手側」限定

`if_target_faster` の分岐なので、**こちらが先手を取れている（＝敵が低速）なら満タン帯でも −1 止まり**。
フォレトス・レジ系・ゴローニャのような低速勢は、**HP満タンから普通に爆発してくる**。
「まだ削っていないから安全」という読みは成立しない。

裏を返すと、**こちらが遅いこと自体が爆発への防御になる**（敵が先手側になり満タン帯の−3が乗る）。

## 3. 第3層 `AI_TryToFaint` との相互作用

- `AI_TryToFaint` は「その技で対象を倒せるなら +4」を与えるが、**爆発は明示的に除外**（`if_effect EFFECT_EXPLOSION, End`）
- **ただし誰も倒せない膠着では**、「自分の最大威力技でない技は −1」により、
  **最大打点である爆発が相対的に +1 で浮上する**
- 満タン低速勢（フォレトス等）の爆発が飛ぶ理由は、これ＋§2の `if_target_faster` で −3 が付かないことで**完全に説明できる**

## 3.5 ダブル固有の帰結【重要】

AIスクリプトはシングル/ダブルで分岐しない。**ただしダブルでは「技×対象」の全組み合わせを個別に採点して最良を取る**
（→[03](03-ai.md) §2）ため、§1の `-10` 条項と §2の `-3` が**対象ごとに**評価される。ここが実戦の読みを変える。

### ① 「ゴースト → -10」は盤面全体の安全装置ではない【確定】
対象ごとの判定なので、**こちらの片方だけがゴーストなら、非ゴースト側を対象にした爆発は減点ゼロ**＝普通に飛んでくる
（ゴースト側は0を食らうだけ）。「ゴーストを出しておけば敵は爆発しない」はシングルの読み。
※現行 v4.1 にゴーストはいないので実害はないが、旧構築（ゲンガー軸）の記述を読み返すときの罠。

### ② 敵の爆発は敵の相方も巻き込むが、それを咎める条項が無い【確定】
だいばくはつは `MOVE_TARGET_FOES_AND_ALLY`。AIのスコアリングに**味方巻き込みのペナルティは存在しない**。
→ **敵の爆発は敵自身の火力を1体分キャンセルすることがある**。
被害見積もりを「爆発＋相方の攻撃」で単純合算すると**過大評価**になる。
同根の確定事項として、**爆発は相方のきあいパンチを自分で潰す**（→[03](03-ai.md) §3）。
一方で**爆発＋爆発は成立する**（ゴローニャ#594はグロス#835の爆発を231-272で確定耐え）。

### ③ 満タン抑制の -3 も対象ごと【推定・要検証】
§2の `-3` は「AIが対象より速いとき」に乗る（`if_target_faster`）。ダブルでは対象ごとに速度比較するため、
**こちらに1体でも敵より速い駒が場にいると、その駒を対象にした評価では -3 が外れる**。
AIは全対象の最良スコアを取るので、**結果として満タンでも爆発が選ばれる**。
→ サンダー(S299)/ラティオス(S350)が場にいる限り、中速の敵の満タン抑制はほぼ機能しない。
※条項の存在は原文確定。**「対象ごとに評価される」部分は採点ループの構造からの推定**であり、原文の逐条確認は未了。

### ④ 敵の相方がしめりけなら、敵は自分の爆発を不発にする？【要検証】
しめりけは**場全体**に効くため、敵の相方がゴルダック/ヌオー（しめりけ）なら**敵自身の爆発も失敗する**はず。
だが §1 の `-10` 条項は**対象の特性しか見ていない**。
→ **AIは自分の相方のしめりけに気付かず爆発を選び、不発で1ターン損する**可能性がある（こちらの得）。
原文の確認が取れていないため**未確定**。確認できれば「しめりけペアは爆発持ちを釣れる」という積極的な使い方が生える。

## 4. 動かない条項

- **AI_Risky**（爆発 +2）・**AI_HPAware**（HP帯抑制）にも爆発条項があるが、
  **バトルタワーのAIフラグには両方とも無い ＝ 一切動かない**。他世代・他施設の解説を持ち込まないこと。

---

## 5. 実機での運用（この章から出る結論だけ）

**警戒すべき瞬間**

- [ ] 爆発持ち24セット（→[01](01-danger-pokemon.md) §3）のHPを**半分以下に削った直後** ＝ +1が乗る。一番来る
- [ ] その敵が**低速**（＝こちらが先手） ＝ **満タンでも来る**。削っていなくても警戒
- [ ] 爆発持ちが**ひかりのかべ等の消極行動**を取った ＝ 前兆
- [ ] **自軍の控えが0（残2体）× 敵ラス1 × 爆発持ち** ＝ 引き分け負けの危険窓
- [ ] その状況で**受け回して相手のPPを枯らさない**（枯れると点数無関係に爆発が出る）

**行動原則**

- 爆発持ちを**中途半端に削らない**。削るなら一撃で落とす、無理なら削る前に退避／まもる
- **メタグロスを場に置く**：敵の爆発24セットを**全て確定耐え**（最大被弾72%）。他3体は落ちる（→[12](12-playbook.md) §4.3）

## 6. シムとの忠実度ギャップ【要注意】

シミュレータは **「敵はHP50%超では自爆しない」** と簡略化している（→[README](README.md) 検証事実#4）。
したがって **§2の「低速の敵は満タンから爆発する」筋を再現できていない**。
実効床 0.2233% は**この負け筋を過小評価**している。

実証：**483連勝時、ラス1のフォレトスがだいばくはつを撃ってきた**（自軍の控えが0＝§1の危険窓）。
ラティオスのひかりのこなで回避して生還したが、当たっていれば**両取り＝引き分け＝敗北**だった。
バグでも異常でもなく、仕様どおりの挙動。
