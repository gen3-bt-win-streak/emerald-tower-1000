# 00. バトルタワー（エメラルド・ダブル）ルールと基礎仕様

> 本ファイルの内容はすべて pokeemerald（逆コンパイル一次資料）のコード行、または複数ソース裏取りで確認済み。
> 根拠行の詳細は [03-ai.md](03-ai.md) と [sources.md](sources.md)。

## 参加ルール【コード確定】

| 項目 | 内容 |
|---|---|
| パーティ | ダブルは**4匹**登録（`FRONTIER_DOUBLES_PARTY_SIZE=4`）、場に2匹ずつ |
| レベル | Lv50戦（敵は固定Lv50）／オープンレベル戦（敵レベル＝こちらの手持ち最高Lv、最低60） |
| 使用禁止 | ミュウツー・ミュウ・ルギア・ホウオウ・セレビィ・カイオーガ・グラードン・レックウザ・ジラーチ・デオキシス |
| ラティオス | **使用可能**（禁止リスト外） |
| アイテムクローズ | 同じ持ち物を2匹以上に持たせられない（**敵パーティも同ルールで生成**される。「持ち物なし」の重複のみ許容） |
| 種族クローズ | 同じ種族2匹は不可（敵側も同様） |
| バッグアイテム | 戦闘中使用不可。**敵AIも道具を一切使わない**（フロンティアでは敵の持ち物データがAIにロードされない） |
| バッジ補正 | フロンティアでは**無効**（通常戦の攻撃+10%等は乗らない） |

## ⚠️ 引き分け＝プレイヤーの負け【重要・先行研究で確認】

第3世代タワーでは**相打ちで両者全滅すると負け扱い**。
→ こちらの最後の1匹での「だいばくはつ」「みちづれ」による相打ちフィニッシュは**負け**。
**常に生存者を1匹残して勝つ**ことをフローに組み込む（Dans Macabre 1090連勝の作者も明記）。

## 連勝の構造と敵の強さ【コード確定】

- 7戦1セット。`challengeNum =「現在の連勝数」÷7`（連勝が途切れるとリセット）。
- 敵トレーナーはIDで管理され、`challengeNum` ごとに下表の範囲から乱数抽選（同一セット内で同じトレーナーは再登場しない）：

| 周回 | 戦数 | 1〜6戦目のトレーナーID | 7戦目（Hard） | 個体値 |
|---|---|---|---|---|
| 1 | 1-7 | 0-99 | 100-119 | 3 / 6 |
| 2 | 8-14 | 80-119 | 120-139 | 3-6 / 9 |
| 3 | 15-21 | 100-139 | 140-159 | 6-9 / 12 |
| 4 | 22-28 | 120-159 | 160-179 | 9-12 / 15 |
| 5 | 29-35 | 140-179 | 180-199 | 12-15 / 18 |
| 6 | 36-42 | 160-199 | 200-219 | 15-18 / 21 |
| 7 | 43-49 | 180-219 | 220-239 | 18-21 / **31** |
| **8以降** | **50-** | **200-299** | **200-299** | **21（ID200-219）/ 31（ID220-299）** |

- 個体値はトレーナーID固定：0-99→3、100-119→6、120-139→9、140-159→12、160-179→15、180-199→18、200-219→21、**220-299→31**。
- **50戦目以降は完全な定常状態**（トレーナーID200-299、約8割がIV31）。1000連勝の95%はこの定常戦。
- フロンティアブレーン（リラ）は**シングル限定**（コード上 `battleMode != SINGLES` で即不出現）。ダブルにブレーン戦・特別戦は一切ない。
- 注意：**記録ミックス／弟子（アプレンティス）機能を使うと、対応する連勝数でその特別トレーナーが優先出現**する。
  敵プールを本DBの想定通りに保つため、**記録ミックスと弟子は使わない**こと。

## 採用モード：オープンレベル【決定】

**本プロジェクトはオープンレベル（ダブル）で挑戦する。**
- 敵レベル＝こちらの手持ち最高レベル（最低60）→ **自軍4匹は全員Lv100に統一**する
  （1匹でも低レベルがいると、その子だけ相対的に敵の攻撃が重くなる。レベルを揃えない理由はない）
- 定常プール実数：**オープン=546セット・143種族**（Lv50なら514セット。全データ→ [data/](data/)）
- オープンレベルでのみ出現する32セット（`FRONTIER_MONS_HIGH_TIER=849` 超）：
  **カイリュー全10セット・バンギラス全10セット・三鳥三犬の最強セット5/6（各2）**
  → 危険度の詳細は [01-danger-pokemon.md](01-danger-pokemon.md) §10
- 好材料：**一撃技・催眠・爆発・ゴースト・しめりけ・ぼうおん・まもる・トリック・ほろびのうたの各所持リストは
  オープンでも1セットも増えない**（Lv50と完全に同一）。増えるのは高種族値の火力枠とQC/こな系アイテムの母数
- 記録の文脈：ダブルの世界記録1,316連勝（Jheisinho・2026-07-29リーダーボード原文確認）は**オープンレベル**（Lv100・エミュ）。
  つまり**オープン・ダブルでの世界記録更新ライン＝1,317連勝**（1000連勝は現行1位に届かず歴代2位相当）

## 勝敗に直結する第3世代の対戦仕様

### ダブルの複数対象ダメージ補正【確定・当初想定より有利】
- **0.5倍になるのは「相手2体のみ対象」の技だけ**（いわなだれ・ふぶき・ねっぷう等、相手2体健在時）
- **じしん・だいばくはつ・じばく（自分以外全体対象）は減衰なしのフルダメージ**（0.75倍になるのは第4世代から）
- → 「ふゆうゲンガー＋じしん/だいばくはつ」構成は第3世代ダブルで理論上最も効率的な全体火力

### だいばくはつ関連【確定】
- 防御を**半分（切り捨て）**にして計算＝実質威力340相当（じばくは260相当）
- ノーマル技なのでゴーストに無効（味方ゲンガーは無傷）／しめりけが場にいると**発動不可**
- まもるで防がれても使用者は倒れる

### ほろびのうた関連【確定】
- 音技。ぼうおんに無効。場の全員（味方含む）にカウント付与。交代でカウント消滅
- カウントは歌った翌ターン終了時から 3→2→1→0（0のターン終了時に瀕死）
- **敵AIは「カウント1」表示の次のターン＝倒れる最終ターンの行動選択で100%交代する**（控えがいる場合のみ。
  くろいまなざし等の交代封じ、または控え全滅なら逃げられず確定で倒れる）→ 詳細 [03-ai.md](03-ai.md)

### 一撃必殺技【確定】
- 命中30固定（回避・命中補正無視）。自分よりレベルが高い相手には無効＝**Lv50戦では常に有効**
- がんじょうで無効。第3世代では**こおりタイプはぜったいれいどを防げない**

## オープンレベル運用の実務メモ

- 自軍は全員**Lv100**（敵もLv100固定になる）。一撃技の有効条件（自分のLv≧相手のLv）も対等のまま
- ブレーン戦なし・特別戦なし（ダブルはリラ不出現。ただし**記録ミックス/弟子機能は使わない**こと）
- 育成コスト：Lv100×4匹（徘徊ラティオスはLv40から要育成）。ふしぎなアメ・げんきのかけら経済は別途計画
- Lv50比の追加リスクはカイリュー/バンギラス/三鳥三犬最強セットのみ＝**対策対象が明確な32セット**
