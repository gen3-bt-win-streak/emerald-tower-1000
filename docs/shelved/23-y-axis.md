## 3. 一次ソースで確定した仕様（本構築の土台）

### ふしぎなまもり（ヌケニン#21）は威力0の技を防がない
```c
if (target.ability == ABILITY_WONDER_GUARD && ...
 && gBattleMoves[gCurrentMove].power)     // ← 威力0なら条件不成立
```
どくどく・やどりぎ・のろい（いずれも`power=0`）は**素通り**。
さらにスリップダメージは全て`if (damage == 0) damage = 1;`で**最低1保証**なので、
**HP1のヌケニンはターン終了時に確実に落ちる**。
※`22-s-axis.md`§4の「通る打点はカビゴンのシャドボのみ」は**攻撃技に限った話**。

### のろい（ゴースト版）
| 項目 | 値 |
|---|---|
| 命中 | **0＝命中判定なし**（回避+6でも必中） |
| flags | **0**＝**まもるで防げない**・マジックコート不可 |
| ダメージ | 最大HPの**1/4**/T（やどりぎの2倍） |
| 代償 | 自分の最大HPの1/2 |
| 失敗条件 | **相手のみがわりのみ**（`jumpifstatus2 SUBSTITUTE → ButItFailed`）。**この場合HPコストは払わない**（`datahpupdate`に到達しない・PP1のみ消費） |

### ふういんは技IDで比較する＝ゴースト版のろいも非ゴースト版も同一ID
```c
if (move == gBattleMons[i].moves[j]) break;   // GetImprisonedMovesCount
```
サマヨールが**のろい＋ねむる**を持ってふういんを撃つと、敵の**両方を封印**する。

| 封印対象 | セット数 |
|---|---:|
| ねむる持ち | 50 |
| のろい持ち | 20 |
| **合計（重複10控除）** | **60/546（11.0%）** |

**1発で2技封じられる10セット**：#458ラグラージ／#516ベトベトン／#525ホエルオー／#534ナッシー／
#556カビゴン／#578エアームド／#666サマヨール／#764レジスチル／#784レジロック／#865バンギラス

### プレッシャー2枚（サンダー＋サマヨール）
`PressurePPLose`は対象がプレッシャー持ちなら攻撃側PPを追加で1減らす（1回の技で2消費）。
**複数対象技はプレッシャー持ちの数だけ呼ばれる**ため、範囲技は最大3消費。
- 敵のこうごうせい/つきのひかり/あさのひざしは**PP5（最大8）** → 2〜3回で枯渇
- 一撃技もPP5 → 2回で打ち止め

### バトルタワーにターン上限は存在しない
`gBattleResults.battleTurnCounter`は統計用で255頭打ち。`B_OUTCOME_DREW`は同時全滅のみ。
**長期戦そのものによる敗北はない**。

## 4. キノガッサ・ヘラクロス8セットの完全処理

ドリルくちばしは**キノガッサ（くさ/かくとう）にもヘラクロス（むし/かくとう）にも4倍**（等倍比6.0倍＝一致1.5×相性4）。

|---|---|---:|---:|---|---|
| #382/#480/#574/#670 | キノガッサ | 261 | 239-262 | 428-504（163%） | 確1 |
| #424 | ヘラクロス | 301 | 206 | 340-400（112%） | 確1 |
| #520 | ヘラクロス | 364 | **295** | 452-532（124%） | 確1 |
| #616/#712 | ヘラクロス | 301 | 269 | 452-532（150%） | 確1 |

**A努力値0（実A216）で8/8確1**。S156振り（実S302）で#520（S295）を1手抜き＝**先手8/8**。
AS特化（S328/A279）と比べ火力ロスなしで**被確1 32→21・被乱1 25→6**に改善する。

| 技タイプ | セット数 |
|---|---:|
| ノーマル（だいばくはつ） | **25** |
| いわ | 1 |
| こおり | 1 |

**れいとうビーム・原子の力では落ちない**（D100振りで圏外）。危険は爆発のみ。
サマヨールはゴーストで爆発無効＝**この27セットに対し被確1=0・被乱1=0・最大被弾153**。

## 5. ハピナスのみがわり（178）が持つ意味

おにび＋リフレクターなしの素の状態でも**266/546（48.7%）が割れない**。
※おにび＋リフレクターを併用した場合は483/546（88.5%）まで伸びるが、本構築では両方とも不採用。

みがわりが立っている限り：
- **一撃技23セットを完全無効化**（`BattleScript_EffectOHKO`は`HITMARKER_IGNORE_SUBSTITUTE`を立てない）
- **あくび・催眠・でんじは等の状態異常を全遮断**
- 急所も人形が受ける

## 6. 既知の弱点と、そのうち対策可能なもの

### 6.1 急所・一撃技・せんせいのツメ ＝ 構造的に「防げない」

| 事実 | 数値 |
|---|---:|
| せんせいのツメ持ち（発動20%） | **75/546** |
| 一撃技持ち（命中30%・防御/回避/急所を全無視） | 23/546 |
| 両方持ち | 12/546 |

**素早さ優位は安全保証にならない**（75セットが20%で先手を奪う）。
急所は`critcalc`で無効化できるのはシェルアーマー/バトルアーマーのみだが、
供給元14種はいずれも脆く、スキルスワップ移植は§8の通り棄却済み。
**したがって「急所を防ぐ構築」は存在しない。問題は防御可否ではなく、敵に何回振らせるか。**

| 1戦の被攻撃回数 | 急所が1回以上出る確率 |
|---:|---:|
| 6回（Z軸：平均約3T×敵2体） | **32%** |
| 26回（Y軸：想定13T×敵2体） | **81%** |
| 52回 | 96.5% |

READMEの原則「相手に乱数を振らせる回数の最小化」は、まさにこの表を指している。
**Z軸は急所を防いでいるのではなく、振らせる回数を1/4以下に抑えている。**

### 6.2 ただし「急所1回＝負け」ではない（Y軸の反論材料）

| 軸 | 急所被確1 | 急所を引かれた時 |
|---|---|---|
| Z軸 | メタグロス**215**/546 | 引かれたら即死しやすい |
| **Y軸** | サマヨール**22**／ハピナス68／ルンパッパ98／サンダー123 | 1発では落ちにくい |

期待損失＝**(曝露回数)×(急所時の致死率)** の積であり、
「曝露26回×低致死率」と「曝露6回×高致死率」のどちらが勝つかは**机上では決着しない**。
加えてY軸は回復手段を3体分持つ（タマゴうみ357／ねむる全回復／やどりぎ吸収）。
S軸が棄却されたのは設営事故率2.9%/戦という**具体的な数字が出たから**であり、
Y軸を同じ土俵に乗せるには長期戦モデルのシミュレータが要る（§7）。

### 6.3 みがわり条項 ＝ 1手を支払って一撃技・状態異常・急所1発を肩代わりする

| 駒 | みがわり | 通常攻撃で割れない | **急所でも割れない** |
|---|---:|---:|---:|
| **ハピナス** | **178** | **266（48.7%）** | **60（11.0%）** |
| サマヨール | 71 | 129（23.6%） | 44（8.1%） |
| ルンパッパ | 91 | 120（22.0%） | 38（7.0%） |
| サンダー | 96 | 88（16.1%） | 39（7.1%） |

1. **ハピナスのみがわりは最優先で維持**（178・48.7%が割れない・タマゴうみ357で再建可能）
2. 他3体のみがわりは**「一撃技・状態異常を1回肩代わりする使い捨て」**と割り切り、維持を狙わない
3. **一撃技23／せんせいのツメ75が見えたら、対面する駒は必ずみがわりから入る**
4. 急所は**1発分しか防げない**（人形が割れる）。連続急所は構造上受け入れる
5. みがわりに1手＋HP1/4を払っても、**やどりぎ・どくどく・のろいは働き続ける**ため削りは止まらない
   （「みがわり→まもる→みがわり」のループ中もスリップダメージが入る）

### 6.5 1戦あたりのターン数
敵4体・平均HP335 → ちきゅうなげ単独なら約13発。実際は4手段の並行適用で短縮されるが、
**Z軸（平均約3T）と比べて1桁多いターン数**になる見込み。
これは6.1の曝露回数に直結するため、実機の時間コストと合わせて**最重要の測定対象**。

## 8. 設計過程で棄却した案（記録）

| 案 | 棄却理由 |
|---|---|
| シェルアーマーをスキルスワップで移植 | 供給元が全員脆い。パールル@しんかいのウロコでも1ターン生存89%。ハピナスがしぜんかいふくを失う副作用も大きい |
| てっぺき（防御+2）を横取り/じこあんじで転送 | てっぺき習得10種が全員鈍足（最速メタグロスS262）。**おにび1つで同等の効果**（被確1が同じ0に）と判明し不要化 |
| こらえる→次ターンにてっぺき | HP1にすると次ターンほぼ確実に落ちる。**満タンで即撃つ方が強い**（89%） |
| よこどりで味方の強化技を奪う | よこどりは「構えて待つ」だけで、対象が技を使わなければ何も起きない。1ターン2アクションで1効果と効率が悪い |
| おにび | ほのお48＋こんじょう24＝**72セット（13.2%）で無効か逆効果**。命中75。のろいに置換 |
| みやぶる | のろいが必中・無効ゼロのため上位互換。ゴースト17へのちきゅうなげ解禁という副次効果も、のろいが直接通るため不要 |
| ころがる（まるくなる＋ふくがん） | 5ターン拘束・A50では威力960でも93/546止まり・A振りすると壁として機能しない |
| ラティアス（キノガッサ/ヘラクロス役） | サンダーのドリルくちばしが**4倍で8/8確1**するため不要。ラティアスはヘラクロスのメガホーンで確1される |
