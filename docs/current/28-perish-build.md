## 1. 勝ち筋

```
第1段  ラティオス＋メタグロスで通常どおり2体を処理する（チーム確定2発 508／爆発込み546）
第2段  敵が残り2体＝控えゼロになったところで、ニョロトノを出してほろびのうた
       → 交代AIトリガー#1（100%）が発動しても交代先が無い
第3段  あくび・まもる・さいみんじゅつでカウント3ターンを渡り切る（2026-11 にダイブを外した。§8.3）
T+4終了時  敵2体が同時に落ちる
```

**19章（ほろびパ・実測46%で棚上げ）との違いはここ**。19章は「2巡のほろびで敵4体を確殺する」設計で、
主因の負け方が「**巡1は成功するが巡2が成立しない＝駒が尽きる**」（2体でちょうど止まるが24.0%）だった。
本構築はほろびを**1巡だけ・しかも控えゼロの相手にだけ**使うので、その負け方が構造的に起きない。

## 2. ニョロトノを採る理由

### 2.1 しめりけ（`Cmd_tryexplosion`）

```c
// Explosion can only fail if any battler has Damp
for (gBattlerTarget = 0; gBattlerTarget < gBattlersCount; gBattlerTarget++)
    if (gBattleMons[gBattlerTarget].ability == ABILITY_DAMP) break;
if (gBattlerTarget == gBattlersCount) { ...成功。使用者のHPを0にする... }
else { gLastUsedAbility = ABILITY_DAMP; gBattlescriptCurrInstr = BattleScript_DampStopsExplosion; }
```

**場の全員を走査**し、失敗分岐は**HPを0にする処理の前**に飛ぶ＝**爆発した敵は無傷で1ターンを空費**する。
爆発／じばく持ちは**24/546**で、敵ペアに入る確率は**8.6%**。19章の負け筋②「相討ち（引き分け＝敗北）**7.7%**」と
ほぼ一致し、**しめりけ1枚でこの負け方が消える**。

**AIには穴がある**。`AI_CBM_Explosion` は `get_ability AI_TARGET` で**対象の特性しか見ない**ので、
ニョロトノを対象にした爆発は −10 で避けるが、**隣の駒を対象にした爆発は減点されない**。実際に撃つと全体走査で
引っかかって不発になる。

**代償**：こちらのメタグロスの爆発も止まる（確定1発 522→255）。**ニョロトノとメタグロスを同時に場へ出さない**運用が要る（§4）。

### 2.3 EV配分（おだやか H240/B154/D108/S8）

**純HDは逆効果**。しめりけ発動中の全走査（`Calm`/`Bold` × H/B/D）で最良が H240/B156/D112（381/225/290）だった。
この走査は**H/B/Dの3軸のみ**で、素早さはこの外側から別途8を切り出している（後述）。

| 型 | 実数値 H/B/D | 被乱1 | 期待被KO |
|---|---|---:|---:|
| **おだやか H240/B156/D112** | 381/225/290 | **1** | **0.23** |
| 純HB ずぶとい H252/B252 | 384/273/237 | 7 | 3.59 |
| 純HD おだやか H252/D252 | 384/187/328 | 10 | 2.96 |

理由は打点の内訳。ニョロトノへの最大打点技を集計すると**物理271／特殊259**でほぼ半々、タイプ別では
でんき102・ノーマル91・じめん76・くさ45・エスパー38・かくとう30。**弱点2つは特殊側で最大勢力だが、
等倍のノーマル＋じめん＋かくとう＋いわ＝215セットが物理**で、Bを削るとそこが刺さる。
種族値がB75/D100で元から特殊寄りなので、D252の限界効用も低い。

**素早さ8振り（2026-09-18 採用）**。ニョロトノとメタグロスは**種族値がどちらも素早さ70**で、
メタグロスの177は余り4振りによる差でしかない。S8で**178**になり、以下3点が同時に取れる。

1. **ダイブでメタグロスのじしんを回避できる。** じしんが貫通する半透明状態は**あなをほるだけ**
   （`BattleScript_EffectEarthquake` が立てるのは `HITMARKER_IGNORE_UNDERGROUND` のみ）で、
   ダイブ（`STATUS3_UNDERWATER`）を貫通するのは**なみのり・うずしお の2つだけ**。
   ただし**ニョロトノが先に潜っていないと成立しない**ので、176のままではメタグロスが必ず先に撃ってしまう。
   （2026-11 にダイブ→たきのぼりへ替えたので、この利点は今は使わない。§8.3）
2. **S176ちょうどの敵20セットに確定先手**（176のままでは同速＝毎回ランダム）。
   ジュゴン#584（つのドリル／ぜったいれいど）・#680（ぜったいれいど）、相手メタグロス#754/#833/#834、
   エアームド#386/#482/#578/#674、ウツボット#491/#587・フシギバナ#441（ねむりごな）ほか。
   **S177・S178の敵は0セット**なので、この帯で失うものは無い。
3. メタグロスと同速（177）で止めると解決しない。**同速はランダム**で1も2も確定しないため、8振りが要る。

**代償は2ポイント**（B225→224・D290→289）。被確1・被乱1・期待被KOはいずれも不変で、
**被乱2が129→131、被乱3が313→319**と微増するだけ。

**2026-10-16 再検証：変更なし**（§9.2）。全性格×全素早さ段階の全探索で、この配分を上回るものは無い。
HP381・B224・D289 がそれぞれ1ポイントの境界に乗っていて、どこから4削っても被乱1が2〜3に増える。

## 3. 詰めの手順（ほろび3ターンの渡り方）

> **2026-11 注**：ニョロトノの技3を ダイブ→たきのぼり に替えた（§8.3）。この節と §3.1 にあるダイブを使う手順（潜って1ターン透かす）は、ダイブ採用時のもの。今は さいみんじゅつ（敵B）・まもる・あくび・カビゴンのまもる で渡り、たきのぼりは削りに使う。

`Cmd_trysetperishsong` は `perishSongTimer = 3`（`battle_script_commands.c:8523`）。ターン終了時に
「0なら倒れる／0でなければ −1」なので、**歌ったターンの後に3ターン耐える**。

| | ニョロトノ | カビゴン | 敵A | 敵B |
|---|---|---|---|---|
| T1 | **ほろびのうた** | **あくび→敵A** | 滅び3 / YAWN 2 | 滅び3 |
| T2 | **まもる**（初回100%） | 攻撃／まもる | YAWN 1 → **T2終了時に眠る** | 行動 |
| T3 | **ダイブ**（潜行） | 攻撃 | 眠り | 行動 |
| T4 | ダイブ浮上・攻撃（または**さいみんじゅつ→敵B**） | 攻撃／まもる | 眠り | 行動 |
| T4終了時 | | | **倒れる** | **倒れる** |

- **ダイブを貫通できるのは なみのり と うずしお だけ**（`battle_scripts_1.s:236-240`／`832-836` の
  `orword gHitMarker, HITMARKER_IGNORE_UNDERWATER` ＋ `setbyte sDMG_MULTIPLIER, 2`）。
  該当 **64/546（11.7%）**・敵ペアに入る確率22.1%だが、**2倍でもニョロトノを落とせるセットは0**。
- **ダイブ中は一撃必殺も外れる**（`battle_script_commands.c:1105-1108`：`NO_ACC_CALC` 系は
  `STATUS3_ON_AIR | STATUS3_UNDERGROUND | STATUS3_UNDERWATER` で失敗）。**貫通するのはロックオン中の零度だけ**で、
  敵にこころのめ＋零度の組み合わせは存在しない。
- **ダイブは強制浮上**なので、素通しは **T1（歌うターン）と T4（浮上ターン）の2ターン**。
- **あくびがそのT4を軽くする**。付与から丸2ターン後のターン終了時に眠らせる（`battle_util.c:1749`）ので
  T2終了時に発動し、T3・T4は敵Aが動かない。眠りは `(Random() & 3) + 2` ＝**行動不能1〜4ターン各25%**（期待2.5）。
  → **T4に殴ってくるのは敵Bだけ**になり、2発ぶんの被弾が1発になる。
- **さいみんじゅつは敵B（あくびを撃たなかった側）に向ける**（§3.0c）。命中60%で、**ニョロトノが先に動けた場合だけ**
  そのターンの敵Bの行動を止められる（S178より遅い敵は236/546）。敵Bが眠っている間は T4 の被弾も消える。
  カビゴンのまもるも T2／T4 の守りに使える（§8.1）。

### 3.0b みがわり（2026-09-15 走者決定・案A）→ 2026-10 に さいみんじゅつ へ変更

> 以下は採用当時の分析。**2026-10 に走者が4枠目を さいみんじゅつ に入れ替えた**（§3.0c）ので、
> ここに書いた一撃必殺・状態異常の無効化は現行構成では成立しない。

4枠目は **ほろびのうた／まもる／ダイブ／みがわり**（くろいきり不採用）。

**一撃必殺を完全に止める。** `Cmd_tryKO` にみがわり判定は無く `gBattleMoveDamage = 対象のHP` を立てるだけだが、
そのダメージは `Cmd_datahpupdate`（`battle_script_commands.c:1865-1882`）で

```c
if (status2 & STATUS2_SUBSTITUTE && substituteHP && !(gHitMarker & HITMARKER_IGNORE_SUBSTITUTE))
    // Target has an active Substitute, deal damage to that instead.
    ...
    gDisableStructs[..].substituteHP = 0;   // 身代わりが壊れるだけ
```

に吸われる。**身代わりが壊れて本体は無傷**。ニョロトノ唯一の穴だった**一撃必殺23セットが0になる**。
状態異常・混乱・メロメロ系の**164/546（30.0%）**、ねこだましのひるみも同様に通らない。

| | みがわり無し | みがわり有り |
|---|---:|---:|
| 一撃必殺が通る敵 | 23 | **0**（立っている限り） |
| 状態異常系が通る敵 | 164 | **0**（同上） |

**みがわり自体は壁にならない。** HPは `381/4 = 95`。

| | セット数 |
|---|---:|
| 最低ロールでも1発で壊される | 360/546（65.9%） |
| 最大ロールなら1発で壊される | 407/546（74.5%） |
| **1発では絶対に壊れない** | **139/546（25.5%）** |

つまり「張ったターンの1発を確実に無効化する」技として使う。まもる・ダイブと合わせて
**T1以外の3ターンを埋める**のが役割で、持続を期待しない。

**くろいきりを落とした根拠**：積み技持ちは **140/546**（うち回避上昇56）だが、
**125はメタグロスの爆発が確定1発**（`MOVE_EXPLOSION` 単体の確定1発500/546）で流せる。
爆発でも落ちない15はほろびのうたが処理する。**「積まれた上に倒せない」場面が構築内に残らない**ので、
くろいきりの出番が無い。

**副次的な利点**：みがわり・まもる・ダイブ・ほろびのうたは**すべてレベル技／TM／HM／教え技**で、
**タマゴ技を1つも使わない**（くろいきりはニョロモのタマゴ技だった）。個体の用意が
「ニョロモを普通に孵化 → ニョロボン → オウジャのしるし交換」だけで済み、16章の手順が短くなる。

### 3.0c さいみんじゅつ（2026-10 走者変更）

4枠目は **ほろびのうた／まもる／ダイブ／さいみんじゅつ**。ニョロトノは Lv1 で覚える
（`sPolitoedLevelUpLearnset`、ニョロモも Lv7）ので個体の用意は変わらない。

**あくびと違い、通常の命中判定を通る。** `BattleScript_EffectSleep`（`battle_scripts_1.s:284-296`）は

```
jumpifstatus2 BS_TARGET, STATUS2_SUBSTITUTE, BattleScript_ButItFailed
jumpifstatus BS_TARGET, STATUS1_SLEEP, BattleScript_AlreadyAsleep
jumpifcantmakeasleep BattleScript_CantMakeAsleep          ; ふみん・やるき
jumpifstatus BS_TARGET, STATUS1_ANY, BattleScript_ButItFailed
accuracycheck BattleScript_ButItFailed, ACC_CURR_MOVE     ; 命中60に回避率・ひかりのこなが乗る
jumpifsideaffecting BS_TARGET, SIDE_STATUS_SAFEGUARD, BattleScript_SafeguardProtected
```

| 効かない・止まる条件 | プール該当 |
|---|---:|
| ふみん／やるき | 4 |
| 相手のみがわり | 11 |
| しんぴのまもり | 3 |
| まもる／みきり（`FLAG_PROTECT_AFFECTED`） | 17／1 |
| ラムのみ（当たっても即治る） | 73 |
| カゴのみ＋ねむる（同上） | 43 |
| **和集合** | **131/546（24.0%）** |
| ひかりのこな／かげぶんしん・ちいさくなる（当たりにくくなる） | 68／56（和集合113） |

**先手でないと意味が薄い。** 眠らせても、相手がそのターン既に動いていれば止まるのは翌ターン以降だけ。
S178より遅い敵は 236/546、そのうち上の131に入らないのは **187**。S178より速い310セットには「当たっても今ターンは殴られる」。
素早さを上げて先手を増やす案は §9.2 で却下（S179にした時点でニョロトノの被乱1が1→2に増える）。

**みがわりから失ったもの**：一撃必殺23セットと状態異常164セットの無効化（§3.0b）。一撃必殺は
**まもる（優先度+3・先手後手は無関係）とダイブ（潜った後は外れる）で受ける**形に戻る。23のうちS178より速いのは6。
**得たもの**：あくびを撃たなかった側（敵B）を眠らせる手段。T4に殴ってくるのは敵Bだけ（§3）なので、敵Bが眠れば素通しは T1 だけになる。

### 3.1 歌ってから引く別ルート

`SwitchInClearSetData`（`battle_main.c:3190-3192`）は**バトンタッチ以外の交代で `gStatuses3` を丸ごと0にする**ので、
**歌った後にニョロトノを引っ込めれば自分のカウントだけ消え、敵2体のカウントは残る**。控えが居るならこちらが上。

| | まもる＋ダイブで耐える | 歌って引く |
|---|---|---|
| 素通しターン | 2（T1・T4） | **1**（T1のみ） |
| 一撃必殺の抽選 | 2回＝49.6% | **1回＝29%** |
| その間の打点 | ゼロ | **普通に殴れる** |

**まもる＋ダイブは「控えが無い局面の保険」**と位置づける。

### 3.2 あくび・ほろびは命中判定を持たない（回避型に強い）

**ほろびのうた**は `.accuracy = 0`・`.target = MOVE_TARGET_USER` で、スクリプト（`bs1.s:1567-1582`）に
`accuracycheck` が**存在しない**。`trysetperishsong` が全スロットへ直接フラグを立てるので、
**回避率・まもる・みがわり・半透明状態のすべてを貫通する**。止まるのは**ぼうおん12セット**だけ（§4-4）。

**あくび**は技データ上 `.accuracy = 100` だが、`BattleScript_EffectYawn`（`bs1.s:2459`）が

```
accuracycheck BattleScript_ButItFailed, NO_ACC_CALC_CHECK_LOCK_ON
```

を渡すため `Cmd_accuracycheck`（`bsc.c:1103-1111`）の**第1分岐**に入り、命中計算そのものを行わない。
回避率と持ち物の減算は第2分岐（`bsc.c:1112-1188`）にあり、ひかりのこなの処理

```c
if (holdEffect == HOLD_EFFECT_EVASION_UP) calc = (calc * (100 - param)) / 100;   // bsc.c:1172-1173
```

には到達しない。よって**ひかりのこな・かげぶんしんの回避上昇・すなかくれ・命中率下降はすべて無視**され、
`.accuracy = 100` という値自体が読まれない。

あくびを止められるのは次の5つだけである。

| 手段 | 判定箇所 | プール該当 |
|---|---|---:|
| ふみん／やるき | `bs1.s:2455-2456`・`bsc.c:6836-6843` | **4**（スリーパー#401/#497/#593/#689） |
| **相手のみがわり** | `bs1.s:2457` | **11** |
| しんぴのまもり | `bs1.s:2458` | 3（ソーナンス#185・ミロカロス#559・ファイヤー#791） |
| まもる／みきり（`FLAG_PROTECT_AFFECTED`） | `bsc.c:1109` | 17／1 |
| 半透明状態（そらをとぶ・あなをほる・ダイブ） | `bsc.c:1107-1108` | — |

**和集合は 36/546（6.6%）**で、5手段のあいだに重複は無い（17+11+4+3+1=36）。
さらに まもる・みがわり は**そのターンに実際に選ばれた場合のみ**効くので、実効の失敗率はこれより低い。
なお「さわぐ」持ちはプールに存在しない（`UproarWakeUpCheck` は空振り）。

**帰結**：ニョロトノとカビゴンの2枚は、**回避型の敵に対して命中率が仕事をしない**。
かげぶんしんを積んでくる相手（ブラッキー#447/#543/#735、エアームドなど）やひかりのこな持ちに、
あくびとほろびは**積まれても通る**。対してメタグロスのコメットパンチ（命中85）やラティオスの
サイキネ（100）は回避に削られるので、**回避型が見えたらあくび・ほろび側に寄せる**のが正しい。

### 7.2 みがわりが「まもる」に足すもの

まもるの代替ではない。**だいばくはつ・じばく・つのドリル・じわれ・ぜったいれいど・ハサミギロチン・じしんは

みがわりが上回るのは次の4点だけである。

1. **まもるの連続使用制限を受けない。** まもるは連続使用で成功率が落ちるが、みがわりは何度でも確実に張れる。
2. **1回張れば持続するので、攻撃しながら守れる。** まもるは1ターンを守りに使い切る。
3. **状態異常を持続的に弾く**（ねむりごな・どくどく・でんじは・あくび）。まもるは撃たれるターンを読む必要がある。
4. **S341でプール最速級**（速い敵は6セットのみ・最速S394）なので先に張れる。

身代わりHPは 311/4＝**77**。これを1発で割れない敵が**104/546（19%）**あり、その相手には居座れる。
一撃必殺・爆発も身代わりが吸う（`Cmd_tryKO`（`bsc.c:7559`）にみがわり判定は無く、
`Cmd_datahpupdate`（`bsc.c:1865`）が身代わりへ振り替える。`BattleScript_ExplosionLoop`（`bs1.s:388-406`）にも
`HITMARKER_IGNORE_SUBSTITUTE` は無い）が、**まもるの完全無効の下位互換**であることに注意。

**反動**は倒した相手のHP/3（中央値110・最大217）。1体倒した後（HP371）の被乱1／被乱2は 20／69 → 40／126、2体目の後（261）は 63／304。
ねむる（カゴ1回）で全快できる。カウンター持ち34型への反射は大きくなる（リングマ#804：おんがえし反射392-462＝耐える、すてみ反射458-540＝高乱数で落ちる）。

採用理由：v6でカビゴンが殴る必要があるのは、ラティオスかメタグロスが先に落ちて残り2体をカビゴンが倒す局面（§10の負け③）だけで、
そこでは確2の差が勝敗に直結する。ほろびの詰めでは殴らなくても敵はT4で落ちるので反動は発生しない＝**反動は必要なときにだけ払うコスト**。

運用：①詰めの局面では撃たない（あくび・まもる）。②殴り役になった試合だけ撃ち、1体倒したらねむる。③カウンター持ちには反射を計算してから。

### 8.3 ニョロトノ：ダイブ→たきのぼり（2026-11）

走者変更。理由（走者）：
- ダイブは攻撃するターンに姿を出す。2ターンで見れば「1ターン透かして1ターン殴る」で、**たきのぼり＋まもると変わらない**。
- たきのぼり＋まもるなら、どちらを先にするか選べて、間に交代も挟める（ダイブは2ターン動けない）。威力も60→80に上がる。
- 1ターン透かすだけなら、まもるで足りる。まもるは味方のじしんも防ぐ（§4-7と同じ処理）。
- ダイブが活きるのは次の2つの場面だけ。
  1. ニョロトノを残したまま、メタグロスのじしんを撃ちたいとき
  2. ほろびの後にニョロトノがもう一度出てきて、まもった後にもう1ターン耐えたいとき（まもるは連続で成功率が落ちる）

- **たきのぼりは みず80・命中100の1ターン技**。第3世代では追加効果は無い（ひるみが付くのは第4世代から）。
  水技は第3世代では特殊なので、特攻216で計算する。個体値の攻撃0（実数値139）は火力に響かず、こんらんの自傷が減るだけ。
- **確定1/2/3発は 2/32/100 → 12/85/173**（§6）。チーム合計で増えるのは確定1発のゴローニャ#402/#594/#690の3セットだけ
  （278→281、爆発込み 522→523）。
- **失ったもの**：上の2場面で、まもるに続けてもう1ターン透かす手。
  §3の手順にあるダイブのターンと、§2.3の「先に潜ってじしんを避ける」は使わない。
- **メタグロスとの併置は禁止しない**（§4-1）。状況に応じてニョロトノ・メタグロスを優先的に切り、じしんを通したり、
  コメパン・シャドボと併せたりする。
