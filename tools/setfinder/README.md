# tools/setfinder/ — タワー型サーチ（静的HTML）

対戦中に見えた情報から、敵の型を絞り込むスマホ向けのページ。50戦目以降の定常プール546型を
ページに埋め込んであり、HTML1枚で動く（サーバー・外部通信・アクセス記録なし）。

| ファイル | 役割 |
|---|---|
| `template.html` | ページ本体。`__DATA__` に型データが入る |
| `build_setfinder.py` | `../engine/` から546型を日本語JSONにして埋め込み、`tower-setfinder.html` を書き出す |
| `tower-setfinder.html` | 生成物（そのまま開ける完成版） |

```bash
cd battle-tower/tools/setfinder && PYTHONHASHSEED=0 python3 build_setfinder.py
# → tower-setfinder.html: 170964 bytes, 546 sets
```

## 仕様

- 種族は入力中に自動で判定する。ひらがな・半角でもよく、途中まで打つと候補ボタンが出る（ブラウザの候補一覧には頼らない）。
- 敵4体の枠に、種族・見えた技・持ち物・特性・素早さ（実数値と比べて速い／遅い／同速）を入れると、候補が自動で更新される。
- 4枠は連動する。ある枠で持ち物が確定すると、他の枠からその持ち物の型が消える（敵チームは種族・持ち物が重複しない）。
- 素早さは個体値31（トレーナーID 220〜299）と個体値21（ID 200〜219）の両方で判定する。同速は「速い」「遅い」の両方に含める。
- せんせいのツメ持ちは「速い」で素早さが足りなくても消さずに、注意を付けて残す。
- 自陣の構成・トレーナー・ダメージ計算には依存しない。
- 入力はブラウザの localStorage にだけ保存する。リセットは1回で全消去、1.5秒以内にもう一度押すと取り消し。
