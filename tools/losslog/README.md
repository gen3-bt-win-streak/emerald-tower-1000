# tools/losslog/ — タワー敗戦ログ（静的HTML）

負けた試合（記録したい勝ち試合も）の流れを、その場でターンごとに残すスマホ向けのページ。
自陣の構成（`team.json`）と50戦目以降の546型を埋め込んであり、HTML1枚で動く（サーバー・外部通信・アクセス記録なし）。
書き出した文章をチャットに貼ると、`/losslog` スキルが `logs/losses/` に保存して解析に入る。

| ファイル | 役割 |
|---|---|
| `team.json` | 自陣の構成（構築名・先発・4体の技と持ち物）。技を替えたらここを直して再生成 |
| `template.html` | ページ本体。`__DATA__` に546型、`__TEAM__` に構成が入る |
| `build_losslog.py` | `../setfinder/` の書き出しを使って `tower-losslog.html` を書き出す |
| `tower-losslog.html` | 生成物。claude.ai に公開する版 |
| `tower-losslog-standalone.html` | 生成物。スマホ等に保存して直接開く軽量版（Webフォント不使用・オフライン） |
| `ingest.py` | 貼り付けられた書き出しを `logs/losses/<日付>-<連勝>.md` に保存し、要約を出す |

```bash
cd battle-tower/tools/losslog && PYTHONHASHSEED=0 python3 build_losslog.py
python3 ingest.py pasted.txt      # または  python3 ingest.py - < pasted.txt
```

## ページの使い方

1. **試合**：日付（既定は今日）・停止時の連勝数・構築・結果（負け／勝ち）・自分の先発2体・トレーナー名（任意）。
2. **敵**：敵A・敵B・控え1・控え2。種族名を途中まで入れると候補が出る。種族を決めると型番号が選べる（持ち物と技4つを表示）。
   分からなければ「型不明」のままでよい。型判別そのものは[タワー型サーチ](../setfinder/README.md)で。
3. **ターン**：1ターンに自分2行・敵2行。「誰が」「何を」「誰に」を選び、**対象に起きたこと**をタグで付ける
   （倒れた／耐えた／ハチマキ／まもられた／無効／外れ／急所／ひるみ／眠り／麻痺／混乱／こおり／やけど／どく／自滅、敵側はツメ先制も）。タグはもう一度押すと外れる。
   使い手が動けなかったときは「何を」で「動けず（ひるみ）」「動けず（眠り）」「混乱で自傷」などを選ぶ。場にいない駒は「誰が」を「（いない）」にする。
   残りHPは自由記入。交代は「交代→誰に」。敵の型が決まっていれば技は選択式、不明なら手入力。「＋ ターンを追加」で次のターン（前のターンの並びを引き継ぎ、「倒れた」を付けた駒は自動で外れる）。
4. **結末**：最後に残っていた駒と所感。
5. **書き出し**：本文（Markdown の表）と、末尾に解析用の `json` ブロックが付く。「コピー」でクリップボードへ。コピーできない端末では本文が選択されるので長押しでコピー。

入力はブラウザの localStorage にだけ保存される（他の端末や claude.ai には渡らない）。「新しい試合」は4秒以内にもう一度押すと取り消せる。

## 書き出しの形式

```
# 敗戦ログ 2026-10-21｜v6｜105連勝で停止
- 日付: 2026-10-21 / 構築: v6 / 連勝: 105 / 結果: 負け
- 自分の先発: メタグロス／ラティオス
- 敵: 敵A カイリュー#851（ひかりのこな）, 敵B プテラ#435（おうじゃのしるし）, 控え1 ラグラージ（型不明）, 控え2 ?

| T | 自分 | 敵 | メモ |
|---|---|---|---|
| 1 | ラティオス れいとうビーム→カイリュー#851（残り少）／メタグロス コメットパンチ→プテラ#435（外れ） | プテラ#435 つばめがえし→ラティオス（急所）／カイリュー#851 じしん | |

- 残り: …
- 所感: …

```json
{"v":1,"date":"2026-10-21","streak":"105",...}
```
```

`json` の `enemies[].set` は型番号（不明なら null）、`turns[].acts[]` は `side`（me／en）・`who`・`act`・`target`・`tags`・`hp`。
